# Clinical Psychology Site Replica

Quero reconstruir no Lovable o site que atualmente está publicado nesta URL:

https://renato-psicologia-clinica.base44.app/

IMPORTANTE: este projeto deve ser uma RECRIAÇÃO VISUAL E ESTRUTURAL do site existente. Não quero uma nova interpretação, redesign ou melhoria estética. Quero que o resultado fique o mais fiel possível ao site original.

OBJETIVO

Analise cuidadosamente o site da URL fornecida e recrie o projeto inteiro dentro do Lovable, de forma independente do Base44.

O resultado final deverá funcionar como um site próprio, com seu próprio código, componentes, estilos e estrutura, sem depender do Base44 para renderização ou funcionamento.

REGRA PRINCIPAL

NÃO altere a identidade visual do site original.

NÃO modernize o design.

NÃO troque a paleta de cores.

NÃO troque as fontes sem necessidade.

NÃO reorganize as seções.

NÃO invente novos elementos.

NÃO remova elementos existentes.

NÃO substitua textos por textos genéricos.

NÃO crie um design “parecido”.

Quero uma reprodução fiel do site que está na URL.

ANALISE ANTES DE CODIFICAR

Antes de implementar, examine cuidadosamente:

1. Estrutura completa da página.

2. Header.

3. Logo.

4. Menu de navegação.

5. Hero/banner principal.

6. Imagens.

7. Textos.

8. Títulos e subtítulos.

9. Botões.

10. Seções e suas respectivas ordens.

11. Cards.

12. Ícones.

13. Depoimentos, caso existam.

14. Formulários, caso existam.

15. Rodapé.

16. Links.

17. Espaçamentos.

18. Margens e paddings.

19. Tamanhos dos elementos.

20. Bordas e arredondamentos.

21. Sombras.

22. Tipografia.

23. Cores.

24. Animações e efeitos, caso existam.

25. Comportamento responsivo.

FIDELIDADE VISUAL

A prioridade máxima deste projeto é a fidelidade visual.

Compare mentalmente cada seção criada com o site original.

O site novo deve manter:

* mesma hierarquia visual;

* mesma ordem das informações;

* proporções semelhantes;

* alinhamentos;

* espaçamentos;

* tamanhos;

* estilos dos botões;

* cores;

* tipografia;

* posicionamento das imagens;

* estrutura do menu;

* estrutura do rodapé.

Se houver alguma característica visual específica no site original, reproduza-a.

RESPONSIVIDADE

O site precisa funcionar perfeitamente em:

* desktop;

* notebook;

* tablet;

* celular.

Não faça apenas uma redução do layout desktop.

Reproduza o comportamento responsivo do site original sempre que for possível identificar.

No celular:

* menu deve funcionar corretamente;

* textos não podem ficar cortados;

* imagens devem se adaptar;

* botões devem permanecer utilizáveis;

* espaçamentos devem ser ajustados;

* nenhuma seção pode gerar overflow horizontal.

IMAGENS

Utilize as imagens do site original quando elas puderem ser acessadas e utilizadas legalmente.

Se alguma imagem não puder ser importada diretamente, NÃO substitua automaticamente por uma imagem aleatória.

Nesse caso, mantenha a mesma proporção, posição, dimensão e função visual da imagem original e utilize um placeholder adequado até que a imagem correta seja fornecida.

Não altere a composição da página apenas porque determinada imagem não está disponível.

TEXTOS

Mantenha exatamente os textos encontrados no site original sempre que possível.

Não reescreva textos.

Não melhore textos.

Não resuma textos.

Não crie textos fictícios.

Não altere chamadas, títulos ou CTAs.

FUNCIONALIDADES

Recrie as funcionalidades existentes no site original.

Se houver:

* botão de WhatsApp;

* links;

* formulário;

* navegação entre seções;

* botão de agendamento;

* links externos;

* redes sociais;

* menus;

* âncoras;

mantenha o comportamento correspondente.

Os links devem apontar para os mesmos destinos do site original quando esses destinos puderem ser identificados.

SEO

Mantenha ou recrie uma estrutura SEO adequada:

* title;

* meta description;

* headings hierárquicos;

* alt text das imagens;

* URLs amigáveis quando aplicável;

* estrutura semântica HTML.

Não deixe o SEO prejudicar a fidelidade visual.

CÓDIGO

Crie o projeto utilizando uma arquitetura limpa e organizada.

Separe componentes quando fizer sentido, por exemplo:

* Header

* Hero

* About

* Services

* Testimonials

* FAQ

* CTA

* Contact

* Footer

Use componentes reutilizáveis somente quando isso não alterar o resultado visual.

Evite código desnecessariamente complexo.

Não crie backend, banco de dados ou funcionalidades que não existam no site original.

IMPORTANTE SOBRE O BASE44

O Base44 deve ser tratado somente como REFERÊNCIA do site atual.

Não quero que o novo projeto dependa do Base44.

O resultado precisa ser um projeto independente que possa posteriormente ser exportado/publicado em serviços como Netlify ou Vercel.

Não incorpore o site através de iframe.

Não faça apenas um embed da URL original.

RECONSTRUA o site.

NÃO FAÇA

Não faça:

* redesign;

* rebranding;

* mudança de cores;

* mudança de tipografia;

* mudança de layout;

* criação de novas seções;

* remoção de conteúdo;

* textos genéricos;

* imagens aleatórias;

* efeitos exagerados;

* animações que não existem no original;

* elementos de SaaS/dashboard;

* componentes desnecessários;

* funcionalidades inventadas.

CRITÉRIO DE SUCESSO

Considere o projeto concluído somente quando a versão criada no Lovable puder ser comparada lado a lado com:

https://renato-psicologia-clinica.base44.app/

e apresentar uma aparência visual extremamente próxima da original.

A prioridade é:

1. Fidelidade visual.

2. Fidelidade estrutural.

3. Responsividade.

4. Funcionalidades existentes.

5. Código limpo.

6. SEO.

NÃO priorize criatividade.

NÃO tente “melhorar” o site.

A tarefa é RECRIAR.
